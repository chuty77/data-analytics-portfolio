## Projects

### 1. [Cross-Source Marketing Campaign Analysis](01-subscription-marketing-analytics) · Power BI
Consolidated two independent sources — an ad server and web analytics — that measured different events and couldn't be summed. Harmonized 32 vendor names into 19, and surfaced that a 54% click-to-session gap was the finding, not an error.
**Focus:** data harmonization · cross-source reconciliation · distinguishing errors from real events

### 2. [Cost vs. Outcomes: Hospital Value Analysis](02-readmissions-vs-cost) · Tableau
Blended a cost source with a readmissions source at different grains — using a data blend, not a join — to answer whether higher spend buys better outcomes. Found one specialty costing twice as much for the same readmission rate.
**Focus:** data blending · category harmonization · value-based analysis

### 3. [Cash Flow & Vendor Risk Dashboard](03-cashflow-vendor-risk) · Power BI
Integrated Accounts Payable, Accounts Receivable, and General Ledger into one star-schema model with aging analysis, DSO, and vendor-risk ranking — built for self-service by a non-technical finance team.
**Focus:** multi-source ETL · star-schema modeling · financial KPIs in DAX

### 4. [Hospital Cost, Readmission & Satisfaction by Condition](04-hospital-condition) · Tableau
Benchmarked each medical condition against the overall average using a FIXED LOD, ranked conditions by cost with a table calculation, and linked three worksheets with dashboard actions into one interactive story.
**Focus:** LOD expressions · table calculations · interactive dashboard design
